## Maintenance requirements

1. Before starting work, refresh branch heads, open PRs, and relevant workflow statuses; report the capture timestamp.
2. Mark a branch active only with direct evidence; uncertain branches remain protected.
3. Record explicit owner/workstream, exact base, current head, blockers, and test workflow for each new branch or PR.
4. Do not change other workers' branches during classification. Propose archival only after proof of preservation and user approval.
5. Connect every shipped app to an exact source/engine/build manifest, not a vague branch name.
