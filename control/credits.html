Credit Budget.

Plan a revised monthly Copilot AI-credit allowance after buying more credits.

Privacy and safety: This calculator runs on your device. It cannot purchase credits or directly change GitHub repository settings. The dispatcher continues to use the existing GitHub variable until you save it there. Updating the budget never turns on automation or authorizes a worker.

Calculate new total

Use confirmed credit quantities from GitHub billing; not dollars or legacy premium requests. If purchasing credits does not increase your monthly AI-credit allowance, do not raise the dispatcher budget.

Apply and verify

  1. Confirm the purchase and amount in GitHub billing.
  2. Copy the new total above and open repository Actions variables.
  3. Edit ARCANA_AI_CREDIT_BUDGET, paste the total (not just the amount purchased), and save.
  4. Run Arcana Copilot Billing Watch. Confirm the refreshed status on the dashboard.

The default reserve is 10% of the new budget unless ARCANA_AI_CREDIT_RESERVE is set. The billing feed remains authoritative for consumed credits and can lag. ChatGPT usage, GitHub Actions minutes, and premium requests use different units.
